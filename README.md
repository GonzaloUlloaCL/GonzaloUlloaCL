## 💼 Proyectos Destacados

### 🤖 [Sistema de Automatización con IA](https://github.com/GonzaloUlloaCL/bot-cobertores-workflow)

**Demo técnico** basado en procesos operativos reales del sector agroindustrial. Lo diseñé y dirigí su construcción con IA.

Sistema inteligente que procesa emails operacionales con **aprendizaje automático de patrones**.

**Stack:** Python 3.13, Gmail API, Google Gemini 2.5, MySQL 8.0, Flask, SQLAlchemy  
**Impacto estimado:** Reduce 10-15h semanales de trabajo manual  

**Features implementados:**
- 🧠 **Fase 0 - Aprendizaje:** Analiza 266 emails históricos, identifica 26 remitentes, genera 16 reglas automáticas
- ⚙️ **Motor de decisión:** Reglas aprendidas → Fallback a IA según scoring de confianza
- 📊 **Scoring inteligente:** Cada clasificación tiene confianza medible (70-100%)
- 📈 **Dashboard operativo:** Flask + MySQL con 15 tablas (8 operación + 7 conocimiento)
- ⚠️ **Sistema de alertas:** Marca para revisión humana cuando confianza < 70%

**Arquitectura:**
```
Gmail Histórico → Scraper → Patrones → Reglas en BD
                                           ↓
Gmail Nuevo → Rules Engine → ¿Regla? → Sí: Aplicar
                                      → No: Gemini IA
```
